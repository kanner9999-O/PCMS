# Quickstart — kiểm chứng spec 045

1. `cd tests && PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=../src python3 -m unittest test_p48_category_archive`
2. Toàn bộ test + `node --test tests/js/`.
3. Bản sao chỉ đọc dữ liệu thật: tổng/Công nợ/báo cáo giống P47; `archived_share` của Gốc vay = phần của Kết + Anh Tự; 3 danh mục ở tab lưu trữ.
4. UI dữ liệu giả (QA `PCMS-QA`): tab mặc định, số lượng, ghi chú tổng, tìm, khôi phục, xóa danh mục chưa dùng, xóa đối tượng rồi thử xóa danh mục, thông báo.
